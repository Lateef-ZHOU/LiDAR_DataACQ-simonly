# LiDAR 数字样机 1.2.1：Web 版离线交付

本包包含完整 Linux amd64 Docker 镜像、配置示例、导入和启动脚本。安装好 Docker 后，导入与运行不需要联网，不依赖其他 LiDAR 镜像或旧交付包。

启动后自动进行环形四轴采集：世界高度角 60°，按方位角 0°、90°、180°、270° 顺序循环，每束累积 10 秒、停稳 2 秒。每束保存谱和径向风，完成四束后反演并保存风廓线。浏览器只是操作窗口，关闭浏览器不会停止采集。

## 1. 运行环境

- 服务器：x86_64 / amd64 Linux，已安装并启动 Docker Engine。Docker 安装程序不包含在本包中。
- 常用工具：Bash、tar、sha256sum；当前用户可运行 Docker，或具有 sudo 权限。
- 不需要宿主桌面、显示器、X11/Wayland 服务、GPU 或 Qt。镜像自带虚拟桌面、Qt 6.11.2、中文字体和软件 OpenGL。
- 操作端：与服务器网络互通的电脑，使用支持 WebSocket 的现代浏览器。
- 建议为解压和镜像导入预留至少 4 GB 磁盘空间，采集数据另计。数据会持续写入，按使用时长安排存储空间。

## 2. 校验、解压和导入

将压缩包和同名 `.sha256` 文件复制到服务器，在所在目录执行：

```sh
sha256sum -c LiDAR-simonly-1.2.1-linux-amd64-web.tar.gz.sha256
tar -xzf LiDAR-simonly-1.2.1-linux-amd64-web.tar.gz
cd LiDAR-simonly-1.2.1-linux-amd64-web
bash ./import.sh
```

`import.sh` 先检查包内文件校验值，再从本地 tar 导入完整镜像 `lidar-simonly-web:1.2.1`。脚本需要 Docker 权限时会调用 sudo；不会下载镜像、依赖或源码。

本包目录结构：

```text
README.md                         使用说明
import.sh                         校验并导入镜像
start.sh                          启动 Web 服务
docker.sh                         Docker 命令入口，按需使用 sudo
lidar-simonly-web-1.2.1.tar         完整镜像
config/simulation.example.json    首次启动的配置模板
docker/web/run.sh                 容器启动脚本
VERSION.txt                       版本、平台和镜像标识
SHA256SUMS                        包内文件校验值
LICENSE、THIRD_PARTY_NOTICES.md    许可说明
licenses/                         随包许可文本
```

## 3. 启动环形采集

在解压目录中执行。将示例 IP **192.168.1.100** 改为服务器实际的局域网 IP：

```sh
WEB_BIND=192.168.1.100 bash ./start.sh
```

容器名默认为 `lidar-sim-web`，服务端口为 `6080`。启动后设备就绪即开始环形采集，不用打开浏览器或点击开始。按包内初始配置，首份风廓线约在一分钟后出现；具体等待时间受云台速度、累积和停稳设置影响。

建议用需要持有输出文件的普通用户运行；脚本会按需为 Docker 调用 sudo。采集文件归启动用户的 UID/GID 所有。未设置 `WEB_BIND` 时，只允许在服务器本机通过 `127.0.0.1:6080` 访问。

启动脚本只使用本地镜像，不自动拉取镜像。若提示未找到镜像，请先执行 `import.sh`。若提示同名容器已存在，按第 6 节启动已有容器或先停止并删除后重新创建。

## 4. 从浏览器访问

在操作电脑浏览器中打开：

```text
http://192.168.1.100:6080/
```

地址使用启动时填写的服务器 IP。页面会直接进入，无需 VNC 密码；能够访问该地址的人都可以操作同一个采集会话。请在约定的局域网或受控网络中使用，服务器防火墙需允许操作电脑访问 TCP 6080。

界面可查看功率谱、风羽图及环形任务进度。默认画质等级 9、压缩等级 0，虚拟屏幕 1600×900，浏览器按比例缩放。系统标题栏及最小化、最大化、关闭按钮已隐藏；关闭服务使用 Docker 命令。任务页的“停止”只停止任务，界面仍保留，可再次“开始”。

关闭浏览器、网络断开或 noVNC 断开均不停止采集；重新打开地址可返回当前会话。页面启用自动重连。

如果只允许 SSH 访问服务器，可保持默认回环绑定：

```sh
# 服务器上
bash ./start.sh

# 操作电脑上：保持此连接打开
ssh -N -L 6080:127.0.0.1:6080 用户名@服务器地址
```

然后在操作电脑浏览器打开 `http://127.0.0.1:6080/`。

## 5. 配置与采集数据

首次启动自动生成 `web-state/config/simulation.json`，以后启动不会覆盖已有文件。可修改云台安装姿态、运动速度、风场、探测器及温度；保留全部字段和合法 JSON 格式。默认风场是线性剪切与随机起伏。

持久修改流程：停止容器，编辑上述 JSON，再启动容器。界面运行时修改的设备/风场参数不会写回 JSON；任务角度和时间也不存入 JSON。

数据保存在解压目录的 `web-state/output/`：

| 子目录 | 内容 |
|---|---|
| `Rawspec/` | 功率谱，无头小端 double，每帧 450×200、720000 字节 |
| `Radialwind/` | 各束径向风 |
| `Windprofile/` | 完成四束后反演的风廓线；含高度、水平风速、风向、垂直风速和时间 |

使用服务器文件管理或 SSH/SFTP 复制这些数据；本 Web 界面不提供文件下载功能。容器重启或删除不删除宿主的配置和数据。停止时不额外排空保存任务，不保证最后一帧已经落盘。

## 6. 查看、停止和再次启动

以下命令在解压目录执行：

```sh
# 查看容器及日志；日志查看中的 Ctrl+C 只结束查看
bash ./docker.sh ps -a --filter name=lidar-sim-web
bash ./docker.sh logs --tail 100 lidar-sim-web

# 停止服务
bash ./docker.sh stop --time 15 lidar-sim-web

# 再次启动：自动开启新的环形采集会话
bash ./docker.sh start lidar-sim-web
```

`docker start` 复用已有容器参数，任务重新开始，不从中断的束恢复。容器异常退出最多自动重启三次；服务器重启或管理员正常停止服务后，按需执行上述 start 命令。

改变 IP、端口、分辨率或任务启动参数时，需要重新创建容器：

```sh
bash ./docker.sh stop --time 15 lidar-sim-web
bash ./docker.sh rm lidar-sim-web
WEB_BIND=192.168.1.100 WEB_PORT=6081 WEB_RESOLUTION=1920x1080 bash ./start.sh
```

此时浏览器地址使用新端口，例如 `http://192.168.1.100:6081/`。删除容器后保留 `web-state`，可继续使用原配置和已保存数据。

## 7. 可选参数与排查

可显式覆盖环形参数，例如每束累积 2 秒：

```sh
WEB_BIND=192.168.1.100 bash ./start.sh \
  --cycleAxis 60 0 90 180 270 --accumulate 2 --settle 2
```

高度角写在四个方位角之前，均为世界坐标、单位为度。累积范围 1–3600 秒，停稳范围 2–600 秒。单轴 `--fixedAxis 60 0` 仅供显式选择，不生成四束风廓线。

| 环境变量 | 默认值 | 作用 |
|---|---|---|
| `WEB_BIND` | `127.0.0.1` | 服务器监听地址，局域网访问需指定服务器内网 IP |
| `WEB_PORT` | `6080` | 浏览器访问端口 |
| `WEB_RESOLUTION` | `1600x900` | 虚拟桌面尺寸 |
| `CONTAINER_NAME` | `lidar-sim-web` | 容器名 |
| `WEB_STATE_DIR` | 本包目录下 `web-state` | 配置和数据目录，可指定绝对路径 |

无法访问时，先检查容器是否运行、日志有无配置错误，再核对 IP、端口和防火墙。浏览器没有风廓线时，先确认环形任务处于运行状态且已完成四束。软件使用 CPU 绘制界面，显示速度受服务器负载和网络影响。

镜像完整包含运行所需的基础层，无需单独导入桌面镜像。版本及镜像标识见 `VERSION.txt`；本包独立于原桌面交付包。
